# Module 11: Unified Risk Scoring Engine

## Objective
Synthesize the independent intelligence pillars of the NEXORAS system into a 0-100 unified risk score, assign risk severity tiers, and provide explainable audit reasons.

## Overview
The Unified Risk Scoring Engine takes as input the signals generated by earlier modules (e.g., Anomaly Ensemble, Vendor Network Intelligence, NetworkX Graph Centrality, and NLP Contract Splitting). It min-max normalizes these signals to a common scale, applies the assigned weight to each pillar, and computes a total score out of 100.

### 5-Pillar Weighting Scheme
The engine incorporates the following intelligence domains:
1. **Tabular Anomaly Ensemble (25%)**: Highlights multi-dimensional financial/cost irregularities.
2. **Vendor Network Risk (25%)**: Captures syndicate formation, monopolies, and geographic anomalies.
3. **NetworkX Graph Centrality (20%)**: Measures influence and structural risk derived from the bipartite entity graph.
4. **Financial/Compliance (15%)**: Assesses specific compliance violations, delay ratios, or budgetary discrepancies.
5. **NLP Contract Splitting (15%)**: Detects identical project descriptions created to bypass value thresholds.

## Key Features
- **Normalization Strategy**: Gracefully handles missing values and dynamic ranges by applying robust min-max normalization across all scored projects.
- **Explainability ("Why Flagged")**: Flags a project and assigns a human-readable reason for any intelligence pillar that contributes >50% of its maximum potential points towards the score.
- **Risk Tiering**: Categorizes the final continuous score into severity levels to prioritize audit reviews:
  - `CRITICAL_RISK`: >= 80.0
  - `HIGH_RISK`: >= 60.0
  - `MEDIUM_RISK`: >= 40.0
  - `LOW_RISK`: < 40.0
